## 🔄 Conversion en Formats Officiels

### Convertir en PDF (depuis Windows)
```powershell
# Depuis navigateur (recommandé)
1. Ouvrir le fichier HTML
2. Ctrl+P → "Imprimer"
3. Sélectionner "Microsoft Print to PDF"
4. Enregistrer
```

### Convertir en PowerPoint (.pptx)
```bash
# Option 1: Utiliser Pandoc (si installé)
pandoc APIX_Invest_Commercial_Pitch.html -t pptx -o APIX_Invest_Commercial_Pitch.pptx

# Option 2: Copier-coller dans PowerPoint
# 1. Ouvrir HTML dans navigateur
# 2. Sélectionner tout (Ctrl+A)
# 3. Copier (Ctrl+C)
# 4. Coller dans PowerPoint (Ctrl+V)
```
