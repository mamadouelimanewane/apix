Sécurité & Conformité

🔒 Couches de Protection
  • Clés API Perplexity/Deepseek tenues côté serveur (proxy sécurisé)
  • Blocage middleware user-agents suspects (curl, wget, bots)
  • Rate limiting intelligent: 120 req/min (app), 20 req/min (API payante)
  • Meta robots tags (noindex, nofollow, noarchive)
  • Anti-scraping côté client (F12, Ctrl+U, Ctrl+C bloqués)
  • Authentification 2FA (credentials + OTP)
  • Données persistées via localStorage crypté (navigateur)
  • RBAC: Investisseur | Agent APIX | Partenaire
✅ Conforme Loi 2008-12 (protection données personnelles)
